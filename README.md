# 별빛공방 · Starlight Forge

개인 포트폴리오와 AI 대화, 일본어 공부방을 함께 운영하는 웹사이트입니다. `starlightForge` 브랜치에서 개발하며, Mac의 nginx가 세 서버를 같은 도메인으로 연결합니다.

| 경로 | 기능 | 접근 |
|---|---|---|
| `/` | 소개와 공개 프로젝트 | 누구나 |
| `/portfolio/` | 전체 포트폴리오 | 누구나 |
| `/resume/` | 이력서 · 인쇄/PDF 저장 | 기본 비공개, 편집에서 공개 선택 |
| `/admin/` | 소개 편집·포트폴리오 등록 | 기존 계정 로그인 |
| `/chat/` | Ollama AI 대화·웹 검색 | 기존 계정 로그인 |
| `/study/` | 하루 일본어 공부방 | 기존 계정 로그인 |

상단의 **홈 / AI 대화 / 학습** 탭과 공통 디자인을 사용합니다. 왼쪽에는 현재 영역의 하위 메뉴만 표시됩니다. 모바일에서는 하위 메뉴가 상단 탭 아래 가로 메뉴로 전환됩니다.

홈의 **콘텐츠 편집**에서 소개·포트폴리오·이력서를 각각 수정합니다. 이력서에는 제목, 요약, 기술, 경력, 학력·교육을 입력할 수 있습니다. 실제 경력·학력은 기본으로 비워 두며, 프로젝트에서 사용한 기술과 확인된 작업만 초기 내용으로 제공합니다. 이력서의 공개를 켜면 방문자가 로그인 없이 열람할 수 있으므로 공개할 개인정보를 확인한 뒤 저장하세요. 공개를 끄면 페이지와 데이터 API 모두 다시 인증을 요구합니다.

빈 프로젝트 목록에는 저장소에서 확인된 **하루 일본어 / 별빛 AI 대화 / 별빛공방 웹사이트** 설명을 한 번만 등록합니다. 기존 프로젝트가 있으면 보존하며, 기본 소개 문구만 새 문구로 갱신합니다. 직접 편집한 문구와 삭제한 프로젝트는 재시작해도 덮어쓰거나 다시 생성하지 않습니다. 이력서는 `data/portfolio/portfolio.sqlite`에 함께 보관되며 학습 JSON 백업에는 포함되지 않습니다.

포트폴리오·이력서 작업에서 정리한 **ProjectP(페달의민족) / ProjectF / ProjectRun / ProjectM**의 웹용 설명과 실행 화면 5장도 등록합니다. 원문의 담당 범위와 팀 역할을 유지하고 프로토타입·출시 프로젝트를 구분했습니다. 검증 수치는 원문에 기록된 2026-10-17 결과임을 표시합니다. 지원 회사 문구·전화번호·이메일·희망연봉과 제출용 PDF 원본은 가져오지 않습니다.

`career-import-v1` 이주는 포트폴리오 서버를 시작할 때 한 번 실행됩니다. 기본 소개만 Unity 개발자 소개로 갱신하고, 기존 사용자 수정 문구와 프로젝트는 보존합니다. 이력서 내용이 이전 기본 예제와 같으면 원문 경력 4개·학력 2개를 반영하면서 기존 공개 설정을 유지합니다. 신규 이력서의 기본값은 비공개입니다. 이미 직접 작성한 이력서는 그대로 두며, **홈 → 이력서 편집 → 작성한 이력서 내용 불러오기**로 새 자료를 편집 화면에 가져와 검토한 뒤 저장할 수 있습니다. 불러오기만으로 서버의 이력서가 바뀌거나 공개되지는 않습니다.

게임 프로젝트와 이미지는 Git의 초기 자료에서 DB로 한 번 복사되며 이후 관리 화면에서 수정·삭제·공개 변경할 수 있습니다. 삭제한 프로젝트는 재시작해도 복구되지 않습니다. 이미지 접근은 해당 프로젝트의 공개 설정을 따릅니다. 이후 옆 세션에서 문서를 수정하더라도 자동 동기화되지는 않으며, 이번 반영은 2026-10-20에 확인한 최종 자료를 기준으로 합니다.

업데이트는 `git pull --ff-only` 후 **포트폴리오·채팅·학습 세 서버를 재시작**하고 브라우저를 새로고침합니다. 기존 `starlightforge.conf.example`의 경로 구성을 사용한다면 Nginx 변경은 필요 없습니다. 새 공통 자원 `/shared/`와 `/portfolio/`, `/resume/`는 포트폴리오 서버가 제공합니다. 기존 인증 파일과 학습 기록은 유지됩니다.

## 포트폴리오 관리

```sh
npm run start:portfolio
```

기본 주소는 `127.0.0.1:3212`입니다. 최초 설치라면 `npm run setup-auth`로 계정을 먼저 설정하세요. 관리 화면에서 이름·분야·한 줄 소개·자기소개·연락처를 수정하고, 프로젝트별 설명·기술 태그·링크·대표 이미지·추가 이미지를 등록할 수 있습니다. 소개 변경은 저장 즉시 공개됩니다. 한 줄 소개는 나중에 작성한 문구를 붙여 넣으면 됩니다.

새 프로젝트는 비공개 초안으로 시작합니다. 미리보기 후 **포트폴리오에 공개**를 선택하고 저장하면 메인에 표시됩니다. 공개 프로젝트는 `/projects/프로젝트ID` 주소로 공유할 수 있습니다. 이미지는 파일당 8MB 이하의 PNG·JPEG·WebP를 지원하며 추가 이미지는 최대 6개입니다. 공개 프로젝트에서 사용하는 이미지만 로그인 없이 열립니다. 공개 후 비공개로 바꾸어도 방문자가 이미 다운로드한 사본까지 회수되지는 않습니다.

`PORTFOLIO_HOST`, `PORTFOLIO_PORT`, `PORTFOLIO_DATA_DIR`, `AUTH_FILE`로 실행 환경을 지정합니다. 소개·프로젝트·이미지는 모두 `data/portfolio/portfolio.sqlite`에 저장됩니다. 기존 학습 JSON 백업에는 포트폴리오와 대화가 포함되지 않습니다. 옮기거나 백업할 때는 해당 서버를 중지한 뒤 데이터 디렉터리를 통째로 복사하거나 SQLite 온라인 백업을 사용하세요. 프로젝트에서 제외하거나 삭제한 이미지는 DB에 비공개로 남습니다.

전체 nginx 경로 예제는 `deploy/nginx/starlightforge.conf.example`, 포트폴리오 자동 실행 예제는 `deploy/org.starlightforge.portfolio.plist.example`입니다. 모든 `/ABSOLUTE/...` 경로를 실제 경로로 바꾸세요. 학습 API는 기존 `/api/`, 채팅은 `/api/chat/`, 포트폴리오는 `/api/portfolio/`를 사용합니다. 세 서버는 루프백에서만 수신하며, nginx의 HTTPS로 외부에 연결합니다. LaunchAgent는 Mac 사용자 로그인 후 실행됩니다. 인증 정보를 바꾸면 세 서버를 모두 재시작하세요.

## 하루 일본어 · JLPT MVP

Mac Studio에서 직접 운영하는 1인용 JLPT 학습 웹앱입니다. 목표 급수를 설정에서 N5~N1로 변경할 수 있습니다. 앱 서버와 SQLite가 학습 기록을 저장하고, 선택적으로 기존 Ollama에 해설을 요청합니다.

## 별빛공방 AI 대화

개인용 채팅 화면은 `/chat/`, 전용 API는 `/api/chat/`입니다. 기존 일본어 학습 서버와 별도 프로세스로 실행합니다.

AI 도우미의 이름은 **스텔라(Stella)**입니다. 부드럽고 지적인 말투와 자연스러운 존댓말을 사용하며, 꼼꼼하고 배려심 있게 설명하도록 지침을 공유합니다. 조건·수치·예외와 사실·추정을 구분하고, 불필요한 과장·훈계·반복적인 자기소개를 피합니다. 같은 지침을 일본어 학습 해설에도 적용합니다. 화면에는 스텔라 이름을 표시하며 사용 모델은 모델 선택란과 답변 이름의 툴팁에서 확인합니다. 실제 표현은 선택한 Ollama 모델의 지시 준수 능력에 따라 달라질 수 있습니다.

```sh
npm run start:chat
```

기본 수신 주소는 `127.0.0.1:3211`이며 기존 `data/auth.json`의 아이디·비밀번호로 모든 화면과 API를 보호합니다. 인증 정보를 바꾸면 학습 서버와 채팅 서버를 모두 재시작하세요. 대화는 별도 `data/chat/chat.sqlite`에 저장되며 기존 학습 JSON 백업에는 포함되지 않습니다.

- 설치된 Ollama 대화 모델 선택, 답변 스트리밍·중지, 대화 기록·삭제를 지원합니다.
- 웹 검색을 켜면 질문의 앞 500자를 기존 검색 서비스 `http://127.0.0.1:8811/search/web`에 보내고 검색 발췌와 출처 링크를 표시합니다. 검색어는 외부 검색 제공업체에도 전달됩니다. 페이지 전문을 수집하지 않습니다.
- Ollama는 기본 `http://127.0.0.1:11434`를 사용합니다. 기존 모래공방과 같은 모델 서버의 연산 자원을 공유하지만 대화 저장소와 인증은 별빛공방에서 관리합니다.
- `CHAT_PORT`, `CHAT_HOST`, `CHAT_DATA_DIR`, `AUTH_FILE`로 실행 환경을 지정할 수 있습니다. `CHAT_OLLAMA_URL`과 `CHAT_SEARCH_URL`은 로컬 HTTP 주소만 허용합니다.
- 외부 HTTPS 연결은 `deploy/nginx/starlight-chat-location.conf.example`을 해당 도메인의 HTTPS server 블록에 추가합니다. 스트리밍을 위해 proxy buffering을 끄고 응답 대기 시간을 늘립니다. 자동 실행 예제는 `deploy/org.starlightforge.chat.plist.example`입니다.

## 학습 앱 실행

Node.js **24 이상**이 필요합니다. 외부 npm 패키지를 설치하지 않아도 됩니다.

```sh
cd /path/to/StudyLangss
npm run setup-auth
npm start
```

브라우저에서 **http://127.0.0.1:3210**을 열고 설정한 아이디·비밀번호를 입력합니다. 비밀번호는 터미널에서 직접 설정하며 입력 중 표시되지 않습니다. 인증 파일이 없거나 손상되면 서버가 시작되지 않습니다. 개발 중에는 `npm run dev`를 사용할 수 있습니다. Windows에서도 같은 명령으로 실행됩니다.

기존 설치를 업데이트할 때는 `git pull --ff-only` 후 최초 한 번 `npm run setup-auth`를 실행하고 앱을 재시작합니다. 기존 학습 데이터는 유지됩니다. 비밀번호 변경·분실 시에도 같은 설정 명령을 실행한 뒤 재시작합니다. 기본 비밀번호나 인증 해제 옵션은 없습니다.

**외부 접속 설정:** [Mac + Nginx HTTPS 구성 안내](deploy/MAC-NGINX.md). 서브도메인·인증서 경로를 수정할 수 있는 설정 예제와 최초 인증서 발급용 HTTP 예제를 제공합니다. 실제 Mac에서 설정·인증서 적용이 필요합니다.

```sh
npm test
```

## 사용 흐름

1. 설정에서 목표 급수와 하루 학습 시간을 선택하고 저장합니다.
2. 오늘 화면에서 학습을 시작하거나 학습실에서 영역을 선택합니다.
3. 답안을 제출하면 정답과 한국어 해설을 확인할 수 있습니다.
4. 풀이 기록과 다음 복습 일정이 자동으로 저장됩니다.
5. 복습함에서 기한이 된 문제를 다시 풉니다.
6. 설정에서 JSON 백업을 다운로드하거나 학습 자료를 추가합니다.

포함된 문제는 **자체 제작한 소량의 학습 예제**입니다. 공식 기출·공식 급수 판정 자료가 아니며 실제 시험 대비를 위한 충분한 문제은행도 아닙니다. N5~N1 각 급수의 예시 난이도는 대략적인 분류입니다. 청해는 Mac 서버의 일본어 합성 음성을 사용하는 보충 연습이며, 실전 청해 음원을 대체하지 않습니다. 일본어 음성은 서버인 Mac에만 설치합니다.

## Ollama 연결

설정에서 서버 주소(기본 `http://127.0.0.1:11434`)를 입력하고 모델 목록을 불러온 다음, 실제 설치된 모델을 선택해 저장합니다. Mac에 있는 정확한 모델 태그를 그대로 사용합니다. 기본 화면과 복습 기능은 Ollama가 없어도 작동합니다.

앱과 Ollama를 **같은 Mac에서 실행**하는 구성을 지원합니다. Ollama 주소는 루프백 주소만 허용합니다. 브라우저가 Ollama에 직접 접속하지 않으므로 Ollama의 CORS 설정이나 외부 포트 공개가 필요 없습니다. 모델을 자동 다운로드하지 않으며 별도 모델을 상시 띄우지 않습니다. 외부 유료 AI API는 이번 MVP에서 연결하지 않습니다.

64GB 전체가 앱에 사용 가능한 메모리는 아닙니다. 기존 대화 모델과 학습 요청이 동시에 실행될 수 있으므로, 실제 모델·문맥 길이·메모리 압력을 확인하면서 운영하세요. AI 해설은 오류가 있을 수 있으며 저장된 기본 해설과 구분해서 확인할 수 있습니다.

## 데이터와 백업

기본 데이터 폴더는 프로젝트의 `data/`입니다. Git에 포함되지 않습니다. 급수를 바꿔도 기존 풀이 기록은 삭제되지 않습니다.

서버가 실행 중일 때 다음 명령으로 JSON 백업을 만들 수 있습니다. 터미널에서 아이디·비밀번호를 입력합니다. 비밀번호를 명령행 인수나 주소에 넣지 않습니다.

```sh
npm run backup
```

`backups/haru-날짜.json`에 저장됩니다. 로그인한 설정 화면에서도 내려받을 수 있습니다. 백업에는 문제·설정·풀이·복습 상태가 포함됩니다. **인증 파일은 포함되지 않으며 복원해도 로그인 정보는 바뀌지 않습니다.** `data/auth.json`에는 scrypt 해시와 salt만 저장되며 Git에서 제외됩니다. 새 Mac으로 옮기면 `npm run setup-auth`로 별도 설정합니다. 복원은 기존 학습 데이터를 덮어쓰므로 현재 백업을 먼저 보관하세요. 다른 디스크에 백업을 복사해야 Mac 디스크 고장에도 대비할 수 있습니다. CLI 백업은 대화형 입력이 필요하므로 기존 무인 실행 작업이 있다면 브라우저 백업 또는 별도의 로컬 백업 정책으로 조정하세요.

환경 변수:

| 이름 | 기본값 | 용도 |
|---|---|---|
| `HOST` | `127.0.0.1` | 앱이 수신할 주소 |
| `PORT` | `3210` | 웹 포트 |
| `DATA_DIR` | `./data` | SQLite 저장 폴더 |
| `AUTH_FILE` | 데이터 폴더의 `auth.json` | 로그인 해시 파일; 설정 명령과 서버에 같은 경로 지정 |
| `APP_URL` | `http://127.0.0.1:3210` | 백업 스크립트의 서버 주소 |
| `BACKUP_DIR` | `./backups` | 백업 출력 폴더 |

## Mac 자동 실행과 개인 기기 접속

먼저 Mac에서 `npm start`로 동작과 Ollama 연결을 확인하세요. 계속 운영하려면 `deploy/kr.haru.jlpt.plist.example`의 경로를 실제 Node 실행 파일과 프로젝트 경로로 바꿔 macOS LaunchAgent로 등록할 수 있습니다. `which node`로 Node 절대 경로를 확인합니다.

```sh
cp deploy/kr.haru.jlpt.plist.example ~/Library/LaunchAgents/kr.haru.jlpt.plist
# 복사한 파일의 /ABSOLUTE/... 경로들을 먼저 수정합니다.
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/kr.haru.jlpt.plist
```

다른 개인 기기에서 사용할 때는 Mac과 기기에 Tailscale을 연결하고 Mac에서 다음과 같이 HTTPS로 전달할 수 있습니다.

```sh
tailscale serve --bg http://127.0.0.1:3210
```

이 앱은 브라우저 기본 로그인 창을 사용하는 **HTTP Basic 인증**으로 모든 페이지와 API를 보호합니다. 비밀번호가 전달되는 외부 접속은 반드시 HTTPS를 사용하세요. Tailscale을 쓰면 기기·사용자 접근 범위를 본인으로 제한합니다. Nginx로 도메인에 연결할 때는 [구성 안내](deploy/MAC-NGINX.md)를 따르고 원래 Host와 Authorization 헤더를 유지합니다. 앱 3210과 Ollama 11434 포트는 인터넷에 직접 공개하지 않습니다. 별도의 로그아웃 기능은 없으므로 공용 기기에서는 비공개 창을 사용하고 종료하세요. 원격 접속 설정과 Mac의 절전·재부팅 후 동작은 실제 Mac에서 확인해야 합니다.

## 자료 추가 형식

설정에서 다음 형식의 JSON 파일을 가져올 수 있습니다. 문자열은 일반 텍스트로 처리됩니다. 권한이 있는 자료만 추가하세요.

```json
{
  "questions": [
    {
      "id": "custom-n5-001",
      "level": "N5",
      "area": "grammar",
      "prompt": "빈칸에 들어갈 조사를 고르세요. わたしは毎日、学校（　）行きます。",
      "choices": ["を", "に", "で", "が"],
      "answerIndex": 1,
      "explanation": "이동의 목적지를 나타낼 때 に를 사용합니다.",
      "tags": ["조사", "이동"],
      "source": "직접 작성"
    }
  ]
}
```

`area`는 `vocabulary`, `grammar`, `reading`, `listening` 중 하나이며 `answerIndex`는 0부터 시작합니다. 독해·청해에는 `passage`를 추가할 수 있습니다. 기존 문항과 충돌하지 않는 고유 ID를 사용하세요.

## 범위

현재 구현: 비밀번호 인증, 급수 선택, 영역별 문제 풀이, 한국어 해설, 자동 복습, 학습 기록, Ollama 추가 해설, 자료 등록, 백업·복원, 반응형 화면, 일본어 단어 암기·문장 빈칸·합성 음성 듣기 연습.

후속 기능: 대규모 검수 문제은행, PDF/OCR 가져오기, 실제 음원 업로드와 구간 반복, 토익·토익 스피킹, 음성 녹음 평가, 외부 API 품질·비용 비교, 자동 일일 학습량 최적화. 현재 앱의 학습 시간은 목표 설정이며 지능형 시간 배분을 보장하지 않습니다.

## 일본어 단어·문장·듣기

학습 탭의 하위 메뉴에 단어 암기, 문장 연습, 듣기 연습이 있습니다. 설정의 JLPT 목표 급수(N5~N1)를 함께 사용합니다. 급수마다 12개씩 총 60개의 자체 제작 단어·예문으로 시작하며, 공식 급수별 단어 목록이나 시험 대비 전체 범위를 뜻하지 않습니다.

- 단어 암기: 읽기와 뜻을 떠올린 뒤 예문·해석을 확인하고 기억 정도를 선택합니다.
- 문장 연습: 예문의 빈칸을 채우고 정답·활용형을 확인합니다. 답안 입력은 선택이며 표기 비교는 참고용입니다.
- 듣기 연습: 일본어 합성 음성의 속도(0.65/0.8/1/1.15배), 반복(1~3회), 음성을 선택하고 받아쓰기·대본 비교를 합니다. 음성 재생을 완료해야 듣기 복습 기록을 저장할 수 있습니다.

추천 순서는 목표 급수 내에서 복습 시간이 지난 항목, 처음 배우는 항목 순입니다. 복습할 항목만 또는 전체 자료도 선택할 수 있습니다. 단어·문장·듣기의 일정은 각각 저장되며, 다시 공부는 약 10분 뒤, 어려움은 최소 하루 뒤, 기억함·쉬움은 더 긴 간격으로 예약됩니다. 기록 화면과 오늘의 학습에서 종류별 복습 수·오늘 저장 횟수를 확인합니다. 이 자기 평가 기록은 기존 문제 풀이 정답률과 구분합니다.

음성은 **Mac 서버에서 합성한 WAV 파일**로 전달합니다. 접속 기기에는 일본어 음성을 설치할 필요가 없으며 Mac 서버에만 설치합니다. 저장된 단어·예문·청해 대본을 기존 인증 아래에서 합성하고 재사용합니다. 별도 유료 API나 대형 모델 없이 macOS 기본 음성 도구를 사용합니다. 실제 시험 음원·음성 인식·발음 평가는 제공하지 않습니다. [Mac 설정과 점검 안내](deploy/MAC-TTS.md)를 따라 `npm run check-tts`를 실행하고 학습 서버를 재시작하세요. iPhone에서 재생이 차단되면 준비 안내 후 버튼을 다시 누릅니다.

영어·중국어는 일본어 기능을 확인한 뒤 확장합니다. 자료에 `language: "ja"`를 명시해 두었으나 현재 화면과 API는 일본어만 지원합니다. 추가 언어는 자료·발음 표기·언어별 음성·시험 설정을 함께 확장해야 합니다.

백업은 `schemaVersion: 2`로 단어·문장·듣기의 자료·복습 카드·입력 이력까지 포함합니다. v2 복원은 기존 문제 기록과 새 연습 기록을 함께 덮어씁니다. 기존 v1 백업도 복원할 수 있으며, v1에는 새 연습 데이터가 없으므로 현재 단어·문장·듣기 기록은 유지합니다. 인증 비밀번호는 백업에 포함하지 않습니다. 새 버전 백업을 구버전 앱에서 복원할 수는 없습니다.
