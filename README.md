# 별빛공방 · Starlight Forge

Mac Studio에서 운영하는 포트폴리오·AI 대화·일본어 학습 웹앱입니다. 관리자가 계정을 만들고 **학습만 / AI 대화만 / 둘 다** 사용할 수 있도록 지정합니다. 학습 기록·대화·알림 기기는 계정별로 보관합니다.

- 개발 브랜치: `starlightForge`
- 운영 주소: [starlightforge.duckdns.org](https://starlightforge.duckdns.org)
- 구성: Node.js 24 이상, SQLite, Ollama, Nginx HTTPS, Web Push
- 화면: **홈 / AI 대화 / 학습** 상단 탭과 영역별 하위 메뉴. 모바일에서는 하위 메뉴가 가로 메뉴로 표시됩니다.
- 디자인: 밝은 벤토 카드와 Spotlight 스타일의 여백·타이포그래피. 홈의 대표 프로젝트 이미지, 이력서 경력 타임라인·기술 카드, AI 대화·학습의 공통 민트/살구 색상과 버튼을 사용합니다.

UI는 크림색 바탕·연보라와 핑크빛·유리 카드·작은 별 포인트로 통일했습니다. 홈의 유리별은 장식용 이미지이며 실제 프로젝트 이미지는 그대로 사용합니다. 꽃·꽃잎 효과는 없습니다. 스텔라·학습 진입 카드는 로그인한 계정의 권한에 따라 표시하고, 이력서 인쇄와 모션 감소 설정을 유지합니다.

스텔라는 SRPG 캐릭터 **미오**의 초상과 차분한 관찰력·신중함을 참고합니다. 홈의 스텔라 카드, 대화 시작 화면과 답변 아바타에 같은 이미지를 사용합니다. 이름은 스텔라로 유지하며, 따뜻한 해요체·관찰과 근거·사실과 추정의 구분·부담을 덜어주는 설명을 [공통 페르소나](lib/persona.mjs)로 대화와 학습 해설에 전달합니다. 게임 속 임무나 관계를 실제 경험처럼 말하도록 설정하지 않습니다. 기존 대화방도 업데이트 후 생성하는 답변부터 반영되며, 이미지·성격만 바꾸므로 음성 모델을 다시 설치할 필요는 없습니다.

UI 개편 내용과 검증 범위는 [검증 기록](docs/ui-refresh/verification.md)에 정리했습니다. 기존 설치는 아래 업데이트 절차 또는 관리자 **사이트 업데이트**에서 적용한 뒤 브라우저를 새로고침하세요. 이번 테마 적용에는 새 모델이나 DB 변경이 없으며, 공통 스타일이 세 서버에서 제공되므로 수동 업데이트 시 세 Node 서버를 재시작하세요.

포트폴리오는 게임 5개와 웹앱 3개, 총 8개 항목입니다. 기존 7개 항목은 2026-10-23 확인한 최근 작업과 실제 화면으로 갱신했고, 10월 24일 더그아웃을 추가했습니다.

이미지와 문구는 [portfolio-latest.mjs](content/portfolio-latest.mjs)에 모았습니다. 게임 이미지는 보존된 실제 실행 캡처이며, 이번 웹 갱신에서 Unity 게임을 다시 실행한 것은 아닙니다. 웹 캡처의 대화·모델 목록은 데모 데이터입니다.

기존 설치는 포트폴리오 서버 재시작 때 이전 기본 문구·이미지와 일치하는 필드만 한 번 교체합니다. 더그아웃은 별도의 한 번 실행하는 처리로 추가하며, 홈 소개가 이전 기본 문구일 때만 함께 갱신합니다. 직접 편집한 필드, 공개 여부·대표작·순서와 삭제한 프로젝트는 유지하며, 새로 설치하면 8개 항목으로 시작합니다. 이후 더그아웃을 편집하거나 삭제해도 재시작 때 되돌리지 않습니다. 프로젝트는 공개 포트폴리오와 이력서의 프로젝트 목록에 함께 표시됩니다.

더그아웃 소개·이미지 경로·저장소 링크는 [baseball-project.mjs](content/baseball-project.mjs)에 모았습니다. 게임은 기존에 클론된 `JinUk-E/BaseBallLife`를 확인했으며 이 웹사이트에는 소개와 이미지가 포함됩니다.

ProjectF/제5병기창과 더그아웃은 포트폴리오 카드의 **웹 플레이 가능** 표시와 상세 화면의 **웹에서 플레이** 버튼으로 접근합니다. `/play/projectf/`와 `/play/dugout/`에서 게임 시작·종료·전체화면·조작 안내·새 탭 열기를 제공합니다. 게임 파일은 공개된 GitHub Pages에서 제공하고 별빛공방은 플레이 영역을 구성하므로, Mac에 게임 파일을 복사할 필요가 없습니다.

플레이 경로·공개 권한·고정 주소 제한·화면 제어는 자동 테스트로 확인했습니다. 현재 작업 환경에서 로컬 브라우저 사용이 꺼져 있어 실제 게임 실행, 저장 파일 가져오기·내보내기, 기기별 전체화면은 아직 확인하지 못했습니다. Mac에 반영한 뒤 사용하는 브라우저에서도 확인해 주세요.

공개 게임 목록과 주소는 [web-games.mjs](content/web-games.mjs)에 고정합니다. 시작 버튼을 누르기 전에는 외부 게임을 불러오지 않습니다. 편집 가능한 링크나 URL 쿼리는 iframe 주소로 사용하지 않으며, 삭제·비공개 프로젝트의 플레이 문서는 서버에서 404 처리합니다. 다른 페이지의 보안 정책은 유지하고 해당 플레이 문서만 자기 게임의 프레임을 허용합니다. 게임이 보이지 않으면 새 탭 열기를 사용할 수 있습니다.

기존 설치는 한 번만 ProjectF의 비어 있거나 기존 공식 ZIP 다운로드인 링크와 더그아웃의 빈 링크를 Pages로 바꿉니다. 직접 편집한 링크·공개 설정·삭제는 보존합니다. 더그아웃 저장은 브라우저와 iframe/새 탭 열기에 따라 달라질 수 있으므로 같은 방식으로 플레이하거나 게임의 저장 내보내기·가져오기를 사용하세요. 별빛공방 계정과 게임 저장을 동기화하지 않습니다.

기존 Windows ZIP은 [0.1.0-preview 릴리스](https://github.com/JinUk-E/StudyLangss/releases/tag/projectf-windows-0.1.0-preview)에 유지합니다. 57,171,233바이트(약 54.5MiB)이며 다운로드·SHA-256 기록은 [projectf-download.mjs](content/projectf-download.mjs)에 있습니다. 웹 게임과 ZIP 모두 Git 기록·앱 DB·Mac 웹서버에 넣지 않습니다.

## 페이지와 접근 권한

포트폴리오·이력서의 GitHub 저장소 링크는 서버가 [GitHub의 저장소 조회 API](https://docs.github.com/en/rest/repos/repos#get-a-repository)로 익명 확인한 공개 저장소만 표시합니다. 비공개·삭제·확인 실패 주소는 공개 JSON에서도 빈 값으로 보내며, 로그인한 방문자에게도 같은 규칙을 적용합니다. 관리자 편집 데이터와 DB의 원래 주소는 유지합니다. GitHub 프로필 주소, 일반 웹사이트와 웹 플레이는 그대로 사용할 수 있습니다. GitHub 토큰이나 추가 설정은 필요하지 않습니다.

판정은 10분간 캐시하므로 공개 여부 변경 반영에 최대 10분이 걸릴 수 있습니다. GitHub 통신·호출 제한 등 확인 실패는 30초 뒤 다시 확인하며, 그동안 저장소 링크를 숨깁니다. 만료한 공개 판정은 실패 시 재사용하지 않습니다. 첫 조회는 외부 확인으로 잠시 지연될 수 있습니다.

| 경로 | 기능 | 접근 권한 |
|---|---|---|
| `/` · `/portfolio/` | 소개·공개 포트폴리오 | 누구나 |
| `/projects/<ID>` | 공개 프로젝트 상세 | 누구나 |
| `/play/projectf/` · `/play/dugout/` | 공개 웹 게임 플레이 화면 | 해당 프로젝트가 공개일 때 누구나 |
| `/resume/` | 이력서·인쇄/PDF 저장 | 전체 공개, 로그인 없이 열람 |
| `/admin/` | 소개·프로젝트·이력서 편집 | 관리자 |
| `/accounts/` | 계정 추가·권한·중지·비밀번호 재설정 | 관리자 |
| `/admin/system/` | Mac 사이트 코드 업데이트·진행 상태 | 관리자 |
| `/chat/` | 스텔라 AI 대화·웹 검색 | 관리자 또는 AI 대화 권한 |
| `/study/` | JLPT·단어·문장·듣기·복습 | 관리자 또는 학습 권한 |
| `/app/` | PWA 설치 안내·본인 알림 기기 관리 | 활성 계정 |

권한은 메뉴와 서버 API에서 함께 검사합니다. 기존 계정은 고정 관리자(`owner`)로 유지하며, 새 계정에 관리자의 개인 기록을 복사하지 않습니다. 학습 권한에는 학습 화면의 AI 추가 해설이 포함되고, 별도 AI 대화 화면은 `chat` 권한으로 제어합니다.

브라우저에서 로그인 실패·권한 부족·없는 페이지·서버 오류가 발생하면 별빛공방 안내 화면을 표시합니다. 오류 상태(401/403/404/429/5xx)와 Basic 로그인 재시도는 유지하고, HTML에는 요청 주소·계정·예외 메시지를 넣지 않습니다. 앱 내부 API 요청은 JSON을 유지하며 5xx 오류는 고정 안내 문구로 응답합니다.

Nginx 자체의 연결 실패·요청 제한도 안내 화면으로 표시하려면 [별빛공방 Nginx 예제](deploy/nginx/starlightforge.conf.example)의 오류 매핑을 운영 설정에 반영해야 합니다. 두 정적 오류 파일은 `public/errors/`에 있으며 Node 서버가 중단돼도 Nginx가 직접 읽습니다. API에는 JSON을 반환하고 원래 오류 상태를 유지합니다. [적용 절차](deploy/MAC-NGINX.md#오류-화면-적용)를 참고하세요.

이력서와 포트폴리오는 전체 공개를 기본으로 합니다. 이번 버전으로 처음 실행할 때 기존 이력서와 등록된 프로젝트를 **한 번만 공개 전환**하며, 작성한 문구·이미지는 유지합니다. 새 프로젝트도 공개가 기본값입니다. 이후 관리자가 개별 공개 체크를 해제하면 비공개 상태는 재시작 후에도 유지됩니다. 콘텐츠 편집·계정 관리·AI 대화·학습은 기존 인증과 권한을 계속 사용합니다.

## 빠른 시작

Node.js **24 이상**이 필요합니다. 한국어·일본어 Qwen3-TTS는 Apple Silicon Mac에서 사용하며, Ollama와 웹 검색은 해당 서비스가 실행 중이어야 합니다.

### 최초 설치

```sh
git clone --branch starlightForge https://github.com/JinUk-E/StudyLangss.git
cd StudyLangss
npm ci
npm run setup-auth
```

터미널에서 관리자 아이디와 12자 이상의 비밀번호를 정합니다. 비밀번호는 입력 중 표시하지 않으며 scrypt 해시로 저장합니다. 인증 파일이 없거나 손상되면 서버가 시작되지 않습니다.

다음 명령을 **각각 별도 터미널**에서 실행합니다.

| 서버 | 명령 | 기본 주소 | 역할 |
|---|---|---|---|
| 포트폴리오 | `npm run start:portfolio` | `127.0.0.1:3212` | 홈·콘텐츠 편집·계정 관리·PWA/푸시 |
| AI 대화 | `npm run start:chat` | `127.0.0.1:3211` | 대화·검색·대화 기록 |
| 학습 | `npm start` | `127.0.0.1:3210` | JLPT·복습·학습 자료·음성 |

개별 개발 화면은 `http://127.0.0.1:3212/`, `http://127.0.0.1:3211/chat/`, `http://127.0.0.1:3210/`에서 확인할 수 있습니다. **전체 탭 이동과 PWA는 세 서버를 같은 HTTPS 도메인으로 연결한 구성**을 사용합니다.

Nginx 예제는 [starlightforge.conf.example](deploy/nginx/starlightforge.conf.example)입니다. `/`·`/api/portfolio/`는 3212, `/chat/`·`/api/chat/`는 3211, `/study/`·나머지 학습 `/api/`는 3210으로 전달합니다. 예제의 인증서·프로젝트 절대 경로를 실제 Mac 경로로 바꾸세요. [외부 접속 구성 안내](deploy/MAC-NGINX.md)에 인증서와 프록시 설정을 정리했습니다.

### 기존 설치 업데이트

업데이트 전 서버를 정지하고 현재 데이터와 인증 파일을 개인 백업합니다. 저장소의 `starlightForge` 브랜치에서 실행합니다.

```sh
git pull --ff-only
npm ci
```

이후 **포트폴리오·AI 대화·학습 세 서버를 모두 재시작**하고 브라우저를 새로고침합니다. 기존 관리자 계정과 기록은 유지되며 `setup-auth`를 다시 실행할 필요는 없습니다.

LaunchAgent를 예제 이름으로 등록했다면 다음 명령으로 재시작할 수 있습니다.

```sh
launchctl kickstart -k "gui/$(id -u)/org.starlightforge.portfolio"
launchctl kickstart -k "gui/$(id -u)/org.starlightforge.chat"
launchctl kickstart -k "gui/$(id -u)/kr.haru.jlpt"
```

실제 등록 이름이 다르면 해당 이름을 사용합니다. 최초 자동 실행 등록에는 `deploy/*.plist.example`의 Node·프로젝트 경로를 바꿔 사용하세요. LaunchAgent는 Mac 사용자 로그인 후 실행됩니다.

### 웹에서 사이트 업데이트

관리자 계정의 **홈 → 사이트 업데이트**에서 **새 버전 확인 → 확인한 버전으로 업데이트**를 누를 수 있습니다. GitHub에 올라간 `starlightForge` 코드를 적용하며, 다른 계정은 화면·API 모두 차단합니다.

Mac에서 이 기능을 수동으로 받은 뒤 기본 이름의 세 LaunchAgent와 기본 `data/` 설치를 사용한다면 한 번 설정합니다.

```sh
npm run setup-updater -- --origin https://starlightforge.duckdns.org
```

설정 명령이 안내하는 세 서버 재시작을 한 번 수행하세요. 이후 별도 작업자가 검증·전체 데이터 백업·코드/의존성 반영·재시작 버전 확인을 처리합니다. 적용 중 접속이 잠시 끊길 수 있으며, 오류 시 Mac 수동 복구가 필요할 수 있습니다. 자동 롤백은 제공하지 않습니다.

업데이트 오류에 `node`만 표시되면 의존성 설치 또는 새 버전 테스트가 실패했을 수 있습니다. 이 문구만으로 Node.js 차단이나 정확한 실패 원인을 판단할 수는 없습니다. 개선된 도우미는 **의존성 설치(npm ci) / 새 버전 자동 테스트**를 구분하고 종료 코드를 표시하며, 실제 명령 출력은 Mac의 비공개 `.site-updater/worker-errors.log`에만 보관합니다. Mac에서 `npm run update-status`로 작업 오류와 도우미 시작 오류를 함께 확인할 수 있습니다. 도우미는 최초 설치 시 복사한 독립 실행본이므로, 이미 설치된 이전 도우미에는 이 개선이 자동 반영되지 않습니다. 기존 설치의 도우미 갱신은 [Mac 업데이트 안내](deploy/MAC-UPDATES.md#진단-개선이-기존-도우미에-반영되지-않을-때)를 참고하세요.

[Mac 설정·복구 안내](deploy/MAC-UPDATES.md) · [그림 중심 안내](docs/updates/guide.html)

## 계정 관리

기존 관리자 계정으로 **홈 → 계정 관리**에 들어갑니다.

1. 새 아이디·비밀번호·비밀번호 확인을 입력합니다.
2. **학습**, **AI 대화** 중 하나 이상 선택합니다. 둘 다 허용할 수 있습니다.
3. 계정을 추가하고 사용할 사람에게 계정과 사이트 주소를 직접 전달합니다.
4. 목록에서 권한 저장, 사용 중지/재개, 비밀번호 재설정을 할 수 있습니다.

아이디는 영문·숫자·`._-`로 1~64자이며 대소문자를 구분하지 않습니다. 비밀번호는 12~256자이고 저장 후 다시 조회할 수 없습니다. 계정은 관리자를 포함해 최대 30개입니다. 아이디는 변경·재사용하지 않으며, 삭제 대신 중지로 기록을 보존합니다.

권한·중지·비밀번호 변경은 **서버 재시작 없이 새 요청부터** 반영됩니다. 진행 중인 AI 대화와 음성 생성은 약 2초마다 권한을 확인하고, 음성 전달 직전에도 다시 검사합니다. 이미 처리 중인 다른 학습 요청이나 푸시 서비스가 접수한 알림은 완료될 수 있습니다.

고정 관리자는 웹에서 중지·권한 변경·비밀번호 변경을 할 수 없습니다. 관리자 비밀번호 복구는 Mac의 `npm run setup-auth`를 사용합니다. 다른 사용자의 자료는 유지되며, 명령 실행 후 세 서버 재시작을 권장합니다.

브라우저는 Basic 인증 정보를 기억할 수 있습니다. 다른 계정을 시험할 때는 별도 브라우저 프로필이나 시크릿 창을 사용하고, 상단의 현재 아이디·권한을 확인하세요. 웹에서 확실한 로그아웃을 보장하지 않습니다.

학습·AI 대화에서 왼쪽 상단 로고로 홈에 돌아와도 로그인한 계정의 메뉴를 유지합니다. 공개 페이지는 세 영역의 기존 로그인 상태를 팝업 없이 확인하며, 브라우저에는 최근 확인한 영역 이름만 기록합니다. 이 수정 적용 시 학습·채팅 서버도 함께 재시작하세요.

## 스텔라 AI 대화

AI 도우미 **스텔라(Stella)**는 부드럽고 지적인 말투, 꼼꼼하고 배려심 있는 설명을 지향합니다. 사실과 추정·조건·예외를 구분하는 지침을 대화와 학습 해설에 함께 사용합니다. 실제 답변 품질은 선택한 Ollama 모델에 따라 달라집니다.

- 설치된 Ollama 모델 선택, 답변 스트리밍·중지, 본인 대화 기록·삭제를 지원합니다.
- Ollama 기본 주소는 `http://127.0.0.1:11434`입니다. 모델을 자동 다운로드하지 않습니다.
- 웹 검색을 켜면 질문 앞 500자를 기존 검색 서비스 `http://127.0.0.1:8811/search/web`에 전달합니다. 검색어는 외부 검색 제공자에도 전달됩니다.
- 검색 결과의 발췌와 출처 링크를 사용하며 페이지 전문을 수집하지 않습니다. 검색 실패는 화면에 표시합니다.
- 다른 계정의 대화 ID를 알아도 해당 계정의 기록을 조회·삭제할 수 없습니다.
- Qwen 설치 후 완료된 본인 답변을 **답변 읽기**로 들을 수 있습니다. 한국어·일본어·자동 선택, 중지를 지원하며 자동 재생하지 않습니다. 답변 읽기는 2,000자까지입니다.

대화와 학습의 모델 연산 자원은 같은 Mac에서 공유합니다. 기본 학습 자료와 복습 기능은 Ollama가 없어도 사용할 수 있습니다. 현재 유료 외부 LLM API는 연결하지 않았습니다.

## 일본어 학습

목표 급수를 **N5~N1** 중 선택하고 하루 목표 시간을 정합니다. 문제 풀이·한국어 해설·추가 AI 해설·복습 일정·학습 기록·자료 가져오기·본인 백업/복원을 제공합니다.

| 기능 | 사용 방식 |
|---|---|
| 문제 풀이 | 어휘·문법·독해·청해 답안 제출 후 정답과 해설 확인 |
| 단어 암기 | 읽기·뜻을 떠올린 뒤 예문을 보고 기억 정도 선택 |
| 문장 연습 | 예문 빈칸 채우기와 정답·활용형 확인 |
| 듣기 연습 | 속도·반복·음성을 선택해 듣고 받아쓰기·대본 비교 |
| 추천·복습 | 목표 급수에서 복습 시간이 지난 항목, 새 항목 순으로 제시 |

기본 자료는 N5~N1 총 60문항과 급수별 12개씩 총 60개의 단어·예문입니다. **자체 제작한 소량의 예제**이며 공식 기출·공식 난도 판정·시험 전체 범위를 뜻하지 않습니다. 단어·문장·듣기의 복습 일정과 기존 문제 정답률은 구분합니다. 듣기는 전체 반복 재생을 완료해야 기록을 저장할 수 있습니다.

학습 설정에서 관리자만 Ollama 서버 주소를 변경합니다. 일반 사용자는 자신의 목표·공부 시간·모델을 선택하며 실제 AI 연결 주소는 관리자 설정을 사용합니다. 백업을 복원해도 일반 사용자가 서버 연결 주소를 바꿀 수는 없습니다.

### Mac에서 음성 합성

**Qwen3-TTS 1.7B CustomVoice 6bit**를 서버인 Mac에 설치해 한국어·일본어 WAV를 폰에 전달합니다. 접속 기기에 모델을 설치하지 않습니다. 한국어 `Sohee`, 일본어 `Ono_Anna`를 차분하고 부드럽게 말하도록 설정했으며, 언어별 음색은 다를 수 있습니다. 단어·예문·듣기 외에 한국어 뜻, 답안 제출 후 해설, 스텔라의 완료된 답변을 읽습니다.

```sh
npm run setup-qwen-tts
npm run check-qwen-tts
open data/tts/qwen-check-ko.wav
open data/tts/qwen-check-ja.wav
# 두 샘플을 듣고 확인한 뒤
npm run check-qwen-tts -- --activate
launchctl kickstart -k "gui/$(id -u)/kr.haru.jlpt"
launchctl kickstart -k "gui/$(id -u)/org.starlightforge.chat"
```

macOS 14 이상·Apple Silicon·arm64 Python 3.12가 필요합니다. [Mac 설치·복구 안내](deploy/MAC-QWEN-TTS.md)의 Python 준비와 Nginx 대기시간 설정까지 먼저 확인하세요. [그림으로 보는 설치 순서](docs/qwen-tts/setup.html)도 제공합니다. **실제 Mac의 MLX 실행·음질·메모리는 아직 검증하지 않았습니다.** Ollama와 동시에 사용할 때는 샘플로 발음·속도·메모리 여유를 확인하세요.

설치 도구는 모델·도우미만 준비하며, 두 언어 실제 합성 점검이 모두 성공한 뒤 활성화합니다. 설정이 없으면 기존 [Mac 일본어 음성](deploy/MAC-TTS.md)을 유지합니다. Qwen 활성화 후 장애가 나면 오류를 표시하며, 복구하려면 `TTS_ENGINE=mac`을 명시합니다. iPhone에서 재생이 차단되면 준비 안내 후 같은 버튼을 다시 누릅니다.

모델은 Mac 내부 `127.0.0.1:8877`에서만 동작합니다. 외부 API 비용은 없으며 최초 설치 때 패키지·모델을 내려받습니다. 웹 업데이트 버튼은 Python 환경·모델을 갱신하지 않으므로, 버전 불일치 시 Mac에서 `npm run setup-qwen-tts -- --refresh` 후 점검·활성화합니다.

## 포트폴리오와 이력서

관리자는 **홈 → 콘텐츠 편집**에서 소개·프로젝트·이력서를 수정합니다. 이력서에는 제목·요약·기술·경력·학력/교육을 작성하고 인쇄/PDF로 저장할 수 있습니다.

- 새 프로젝트와 이력서는 기본 비공개입니다. 공개로 저장한 자료만 방문자가 열람합니다.
- 이미지는 파일당 8MB 이하 PNG·JPEG·WebP, 추가 이미지는 최대 6개입니다. 공개 프로젝트가 사용하는 이미지만 공개합니다.
- 확인된 게임 프로젝트 **ProjectP(페달의민족) / ProjectF / ProjectRun / ProjectM**의 설명과 실행 화면을 초기 자료로 반영했습니다.
- 초기 자료 이주는 한 번만 실행하며 기존 수정 문구·프로젝트·공개 설정을 보존합니다. 삭제한 프로젝트는 재시작해도 다시 만들지 않습니다.
- 직접 작성한 이력서는 보존합니다. **작성한 이력서 내용 불러오기**로 제공 자료를 편집 화면에서 검토한 뒤 저장할 수 있습니다.
- 이전 기본 이력서를 그대로 사용했다면 포트폴리오 서버 재시작 때 읽기 쉽게 다듬은 문구로 갱신합니다. 직접 수정한 이력서는 유지하므로 새 문구를 쓰려면 **작성한 이력서 내용 불러오기 → 이력서 저장**을 이용하세요. 기존 공개 여부는 유지합니다.

초기 반영 자료는 2026-10-20에 확인한 내용을 기준으로 합니다. 다른 세션의 문서와 자동 동기화하지 않습니다. 공개 후 방문자가 다운로드한 사본까지 회수할 수는 없습니다.

## 휴대폰 설치와 푸시 알림

**홈 → 앱 설치·알림**에서 설치 방법과 본인 기기의 알림 상태를 확인합니다.

1. 아이폰·아이패드: Safari 공유 → 홈 화면에 추가 → 추가한 아이콘으로 실행합니다.
2. 안드로이드: Chrome 메뉴에서 앱 설치 또는 홈 화면 추가를 선택합니다.
3. 로그인 후 기기 이름을 적고 **이 기기에서 알림 켜기**를 눌러 OS 권한을 허용합니다.
4. **이 기기로 테스트 보내기**를 눌러 실제 도착과 알림 클릭을 확인합니다.

아이폰 Web Push는 iOS 16.4 이상에서 홈 화면에 추가한 웹앱으로 사용합니다. 설치한 앱에서 다시 로그인을 요구할 수 있습니다. PWA는 개인 페이지·대화·API를 오프라인 캐시하지 않습니다.

Mac의 최초 푸시 설정:

```sh
npm run setup-push -- --origin https://starlightforge.duckdns.org --contact https://starlightforge.duckdns.org
```

설정 후 포트폴리오 서버를 재시작합니다. 기존 키는 덮어쓰지 않으며 매 업데이트마다 재생성할 필요는 없습니다. 설치 자원은 공개하고 `/app/`와 기기 API는 인증으로 보호합니다.

- 계정별 최대 10기기, 기기당 60초 발송 간격을 적용합니다.
- 잠금 화면에는 민감한 본문 대신 고정 안내를 표시합니다.
- 푸시 서비스의 **접수 성공과 실제 폰 수신은 다릅니다.** OS 권한·집중 모드·네트워크에 따라 수신을 확인해야 합니다.
- 만료된 구독은 정리하며, 애매한 발송 결과는 자동 재전송하지 않습니다.
- 다른 계정의 기기를 조회·삭제·테스트할 수 없습니다. 같은 브라우저에 이전 구독이 남으면 해제 후 새 계정으로 연결합니다.

Mac에서 다음 명령은 **관리자(owner)가 등록한 기기들에 실제 알림을 발송**합니다. 다른 사용자 기기를 포함하지 않습니다.

```sh
npm run send-push -- --all
# 특정 관리자 기기만 선택: npm run send-push -- --id <기기ID>
```

현재는 설치·기기 등록·테스트·수동 발송·전달 모듈까지 구현했습니다. **주간 검색 리포트의 자동 예약과 푸시 연결은 후속 기능**입니다.

| 소개·포트폴리오·이력서·이미지 | `data/portfolio/portfolio.sqlite` |
| 푸시 키·기기 구독 | `data/push/vapid.json` · `data/push/push.sqlite` |

기본 데이터는 Git에서 제외합니다. 각 사용자는 학습 설정에서 **본인의 학습 JSON**을 내려받고 복원할 수 있습니다. CLI 백업은 실행 중인 학습 서버에 로그인해 만듭니다.

```sh
npm run backup
```

터미널에서 학습 권한이 있는 계정과 비밀번호를 입력합니다. 기본 출력은 `backups/haru-날짜.json`입니다. v2 백업은 문제·설정·풀이·복습·단어/문장/듣기 기록을 포함합니다. v1 복원은 단어·문장·듣기 기록을 유지합니다. 복원은 해당 계정의 자료를 덮어쓰므로 현재 백업을 먼저 보관하세요.

**학습 JSON에는 계정 인증·대화·포트폴리오·푸시 비밀값이 포함되지 않습니다.** Mac 전체를 옮길 때는 세 서버와 수동 발송을 정지하고 인증·공통 계정 DB·사용자 DB·포트폴리오·푸시 경로 전체를 개인 백업합니다. SQLite WAL/SHM 파일이 있으면 함께 포함하고 Mac 사용자 전용 권한을 유지합니다. 새 기능 사용 후 구버전 서버를 섞어 실행하지 않으며, 롤백은 업데이트 전 코드와 데이터 전체를 함께 복원합니다.

## 환경 변수

기본값은 저장소 루트 기준입니다. 커스텀 경로를 사용하면 설정 명령·서버·발송 명령에도 같은 환경 변수를 적용합니다.

| 이름 | 기본값 | 용도 |
|---|---|---|
| `HOST` / `PORT` | `127.0.0.1` / `3210` | 학습 서버 |
| `DATA_DIR` | `data/` | 학습 데이터 |
| `CHAT_HOST` / `CHAT_PORT` | `127.0.0.1` / `3211` | AI 대화 서버 |
| `CHAT_DATA_DIR` | `data/chat/` | 대화 데이터 |
| `CHAT_OLLAMA_URL` | `http://127.0.0.1:11434` | 대화용 Ollama |
| `CHAT_SEARCH_URL` | `http://127.0.0.1:8811` | 대화용 검색 서비스 |
| `PORTFOLIO_HOST` / `PORTFOLIO_PORT` | `127.0.0.1` / `3212` | 홈·관리·PWA 서버 |
| `PORTFOLIO_DATA_DIR` | `data/portfolio/` | 공개 콘텐츠 데이터 |
| `AUTH_FILE` | `data/auth.json` | 관리자 인증 원본 |
| `AUTH_USERS_FILE` | `AUTH_FILE` 옆 `accounts.sqlite` | 공통 계정 DB |
| `PUSH_DATA_DIR` | `data/push/` | 푸시 기기 DB |
| `PUSH_CONFIG_FILE` | 푸시 데이터 폴더의 `vapid.json` | VAPID 설정 |
| `APP_URL` | `http://127.0.0.1:3210` | 학습 백업 스크립트의 접속 주소 |
| `BACKUP_DIR` | `backups/` | 학습 JSON 백업 출력 |
| `TTS_ENGINE` | 활성 설정 있으면 `qwen`, 없으면 `mac` | 명시적으로 Qwen 또는 기존 일본어 음성 선택 |
| `TTS_CONFIG_FILE` | `data/tts/qwen.json` | 학습·대화 공통 Qwen 활성 설정의 절대 경로. `DATA_DIR`와 별개 |

**세 서버의 `AUTH_FILE`과 `AUTH_USERS_FILE`은 같은 경로여야 합니다.** 학습 서버와 `setup-auth`는 `DATA_DIR`를 바꾸면 기본 인증 파일 위치도 따라 바뀌므로, 커스텀 설치에서는 공통 인증 경로를 명시하세요. `PORTFOLIO_DATA_DIR`만 별도로 지정하면 푸시 기본 경로는 그 폴더 아래 `push/`이며 `PUSH_DATA_DIR`·`PUSH_CONFIG_FILE`이 우선합니다.

앱 서버는 기본적으로 루프백에서 수신합니다. 외부 접속은 Nginx의 정상 HTTPS를 사용하고 Host·Authorization 헤더를 전달합니다. 앱·Ollama 포트를 인터넷에 직접 노출하지 않습니다. Mac 전원·로그인 세션·서버·인터넷 연결이 필요합니다.

## 학습 자료 가져오기

학습 설정에서 본인 자료로 JSON을 가져올 수 있습니다.

```json
{
  "questions": [
    {
      "id": "custom-n5-001",
      "level": "N5",
      "area": "grammar",
      "prompt": "빈칸에 들어갈 조사를 고르세요. わたしは毎日、学校（　）行きます。",
      "choices": ["を", "に", "で", "が"],
      "answerIndex": 1,
      "explanation": "이동의 목적지를 나타낼 때 に를 사용합니다.",
      "tags": ["조사", "이동"],
      "source": "직접 작성"
    }
  ]
}
```

`area`는 `vocabulary`, `grammar`, `reading`, `listening` 중 하나이고 `answerIndex`는 0부터 시작합니다. 독해·청해에는 `passage`를 추가할 수 있습니다. 고유 ID와 사용 권한이 있는 자료를 사용하세요.

## 구현 상태와 검증

`starlightForge`의 코드 변경은 [Mac update validation](https://github.com/JinUk-E/StudyLangss/actions/workflows/macos-validation.yml)에서 Apple Silicon macOS·Node.js 24로 검증합니다. 운영 도우미처럼 환경변수를 제한하고 `npm ci --ignore-scripts`와 전체 Node 테스트를 실행합니다. [2026-10-21 실행](https://github.com/JinUk-E/StudyLangss/actions/runs/39548511484)은 **183개 통과·실패 0·건너뜀 0**입니다. 운영 Mac의 Node 경로·설치 상태·네트워크와 실제 LaunchAgent 배포는 별도 확인 대상이며, CI는 운영 서버를 변경하지 않습니다.

Qwen 변경을 포함해 Windows Node.js 24.15.0에서 전체 회귀 테스트를 실행했습니다. 계정 격리·권한 회수·음성 캐시 분리·저장된 답변만 읽기·설치 활성화·WAV 검증·큐 제한을 확인했습니다. Python 표준 라이브러리의 모의 서비스 테스트 7개도 통과했습니다. 최신 결과는 [검증 기록](docs/qwen-tts/verification.md)에 보관합니다.

팀의 운영·보안·UI 검토를 반영했습니다. 임시 계정과 테스트 음원으로 브라우저의 답변 읽기·한국어 뜻 읽기·언어 변경 및 390px 배치를 확인했습니다. **실제 Mac의 Nginx·MLX 음성·LaunchAgent, 휴대폰 로그인·푸시 수신은 해당 기기에서 확인해야 합니다.**

기획 단계인 기능은 다음과 같습니다.

- 주간 관심 정보 검색·리포트 보관·자동 알림: [기획서](docs/stella-digest/overview.html), [상세 명세](docs/stella-digest/plan.md)
- 일본어 기능 검증 후 영어·중국어, TOEIC·TOEIC Speaking 확장
- 대규모 검수 문제은행, PDF/OCR, 실제 음원·발음 평가, 외부 AI 품질·비용 비교
