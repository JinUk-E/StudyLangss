홈 / 앱 설치·알림

가까이 두는 별빛공방

홈 화면에서 열고, 이 기기로 알림을 받아보세요. 설치와 알림 설정은 각각 진행합니다.

01

홈 화면에 설치

설치 방법을 확인하고 있습니다.

직접 설치하는 방법
  • 아이폰·아이패드: Safari에서 사이트를 열고 공유 → 홈 화면에 추가를 선택하세요. 추가한 아이콘으로 앱을 열어 알림을 켜세요.
  • 안드로이드: Chrome 메뉴 → 홈 화면에 추가 또는 앱 설치를 선택하세요.
  • Mac·PC: 주소창의 설치 아이콘이나 브라우저 메뉴를 확인하세요. 지원 여부는 브라우저마다 다릅니다.

인터넷 연결과 로그인이 필요합니다. 설치한 앱에서 다시 로그인할 수 있습니다. 개인 자료를 오프라인으로 저장하지 않습니다.

02

이 기기에서 알림 받기

현재 계정을 확인하고 있습니다.

브라우저 권한확인 중
현재 계정의 서버 등록확인 중

알림 지원 상태를 확인하고 있습니다.

테스트는 이 기기에 고정 안내 문구 1개를 보냅니다. 접수 성공과 실제 알림 도착은 다릅니다. 잠금 화면·집중 모드와 OS 알림 설정도 확인하세요.

다른 계정으로 로그인해도 OS 알림 권한은 유지됩니다. 이전 계정에 연결된 구독은 자동으로 가져오지 않습니다. 이전 계정에 로그인할 수 없다면 이 화면에서 브라우저의 남은 구독을 해제한 뒤 현재 계정으로 다시 연결하세요.

브라우저가 기존 Basic 로그인 정보를 유지하면 다른 계정으로 전환되지 않을 수 있습니다. 현재 계정 이름을 확인하고, 별도 브라우저 프로필이나 시크릿 창으로 로그인하세요.

이번 기능에는 주간 검색이나 예약 발송이 연결되어 있지 않습니다. 알림은 일반 안내 문구로 표시합니다.

03

등록한 기기

최대 10대까지 연결할 수 있습니다. 기기를 삭제해도 해당 기기의 OS 알림 권한은 유지되며, 이미 전송된 알림은 회수되지 않습니다.
