STARLIGHT FORGE · PWA / WEB PUSH · 2026.10.20

별빛공방을
폰 홈 화면에 가까이

웹을 앱처럼 열고, 짧은 알림을 받을 수 있게 만들었습니다. Mac에서 한 번 설정한 뒤 폰에서 설치하고 알림을 켜세요.

브라우저의 정식 설치 방식입니다. APK나 미서명 iOS 앱을 설치하는 방식이 아닙니다. 앱스토어 등록이나 개발자 계정 가입 없이 사용할 수 있습니다.

준비는 세 단계

Mac에서 최초 한 번

저장소 폴더에서 실행하세요. 기존 로그인·학습·대화 자료는 유지합니다.

git pull --ff-only
npm ci
npm run setup-push -- --origin https://starlightforge.duckdns.org --contact https://starlightforge.duckdns.org

이후 기존 방식으로 portfolio·chat·study 세 서버를 재시작합니다. 키가 이미 있으면 설정 명령은 덮어쓰지 않습니다. 업데이트 때마다 새 키를 만들 필요는 없습니다.

data/push/에는 개인키와 기기 구독이 저장됩니다. Git에 올리지 말고, 서버를 정지한 뒤 개인 백업에만 보관하세요. 별도 데이터 경로를 사용한다면 서버와 명령의 환경 변수를 같게 맞춥니다.

기존 Nginx 예제는 같은 도메인의 새 경로도 전달합니다. 푸시를 위해 새 외부 포트를 열 필요는 없습니다.

폰에서 연결

순서할 일
접속https://starlightforge.duckdns.org/app/에서 기존 계정으로 로그인합니다.
설치아이폰 Safari 공유 → 홈 화면에 추가. 안드로이드 Chrome 메뉴 → 앱 설치 또는 홈 화면 추가.
허용추가한 아이콘으로 열어 홈 → 앱 설치·알림 → 기기 이름 → 이 기기에서 알림 켜기. OS 권한 창에서 직접 허용합니다.
확인테스트 보내기를 누르고 실제 알림을 확인합니다. 앱을 닫은 수신도 확인하고 알림을 눌러 다시 열어봅니다. 로그인을 다시 요구할 수 있습니다.
아이폰은 iOS16.4 이상 + 홈 화면 설치가 필요합니다. 집중 모드·알림 요약·OS 권한이 수신에 영향을 줄 수 있습니다. ‘푸시 서비스 접수’는 폰 수신 확인과 다릅니다.

이번 버전의 범위

완료한 기능추가 확인·후속 기능
설치 설정과 아이콘
기기별 구독·해제·테스트
Mac 수동 발송과 전달 모듈
잠금 화면의 일반 안내		실제 Mac 인증서·Nginx 확인
사용자 폰의 권한·백그라운드 수신
주간 검색 리포트·예약과 연결

알림은 기기당60초 간격, 최대10대입니다. 만료된 수신처는 정리하고 애매한 결과는 자동 재전송하지 않습니다. 해제해도 이미 접수된 알림은 도착할 수 있습니다.

보안 경고가 나오면 멈추고 주소·인증서를 확인하세요. PWA라도 인증서 오류·유해 사이트 판정·회사 관리 정책으로 제한될 수 있습니다. 경고를 우회하는 설정은 필요하지 않습니다.

팀 검토와 근거

기술·운영·사용 경험 세 역할의 기획 검토를 반영했습니다. 독립 코드 검토에서 발견한 서버/명령의 경로 불일치는 공통 함수로 수정했습니다. 모두 Codex 계열이며 별도 외부 CLI로 문서를 전달하지 않았습니다.

자동 시험은 인증·구독 보존·안전한 전송·서비스 워커 동작을 검증합니다. 실제 폰 수신 시험을 대신하지 않습니다.
