AI 대화 탭 안에 네 메뉴

메뉴여기서 하는 일
스텔라와 대화지금처럼 질문하고 대화합니다.
정기 리포트주제·검색식·시각을 설정하고 미리보기, 예약 켜기·중지를 합니다.
리포트 보관함전체 내용과 출처, 생성·발송 상태를 각각 확인합니다. 화면을 닫은 미리보기도 여기 남습니다.
알림 연결수신처를 등록하고 문구·대상을 확인한 뒤 테스트를 보냅니다. 비밀값은 다시 표시하지 않습니다.
먼저 읽고, 그다음 켜기. 미리보기는 웹에만 저장합니다. 예약은 기본 꺼짐이며, 사용자가 켜야 외부 발송이 시작됩니다.

3. 월요일 예약

재시작과 누락·오류를 시험합니다. 실제 월요일 한 회를 관찰해 운영을 확인합니다.

코드 완료와 실운영 검증 구분

초기 한도: 예약 5개 · 검색식 3개/예약 · 후보 15개 · 핵심 5건 · 채널 1개. 검색과 요약은 순서대로 처리합니다.

놓치거나 중복 보내는 일을 줄이는 규칙

상황사용자가 보게 될 결과
Mac이 꺼져 있었음48시간 안에 돌아오면 가장 최근 한 회만 보완합니다. 그보다 오래되면 누락을 기록합니다.
대화와 요약이 겹침대화를 우선합니다. 생성 시작 후 30분 또는 요약 중단 3회면 종료하고 상태를 남깁니다.
확인된 새 자료 없음‘확인된 새 소식 없음’. 검색 실패와 구분하며 이 알림은 설정에서 끌 수 있습니다.
예약의 검색·요약 실패같은 정상 채널로 짧은 상태 알림을 보냅니다. 미리보기·발송 요청 없는 수동 생성은 외부 알림이 없습니다. 채널 자체 장애는 웹에서 확인합니다.
보냈지만 응답이 끊김‘발송 결과 불명’. 자동으로 다시 보내지 않습니다. 사용자가 채널 확인 후 재발송합니다.
수신처·설정 변경진행 중 미발송 건은 취소합니다. 수신처 교체 시 재시험하고 예약을 다시 켭니다.
정확한 시각과 완벽한 한 번 전달은 보장하지 않습니다. 생성·네트워크 지연이 생길 수 있습니다. 안전한 발송 재시도만 최대 3회, 저장 후 2시간 안에서 허용합니다. 예정 시각 48시간 한도도 함께 적용합니다.
