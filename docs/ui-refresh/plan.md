# 별빛공방 UI 개편

2026-10-21 · main-codex · M — 여러 화면의 공통 스타일·렌더링을 조정하는 가역적 UI 변경. 계정·저장 형식·API·모델·배포 방식은 기존 계약을 유지한다.

사용자는 Bento 카드와 Spotlight의 여백·타이포그래피를 섞어 홈·이력서를 새로 구성하고 AI 대화·학습도 통일하도록 실행을 요청했다. 유료 템플릿의 코드·이미지를 가져오지 않고 기존 순수 HTML/CSS/JS와 본인 프로젝트 이미지를 사용해 독자적으로 구성한다.

## 확정할 방향

- 밝은 회백색 배경, 흰 카드, 짙은 글씨, 청록 포인트와 소량의 따뜻한 보조색. 외부 글꼴·라이브러리 없이 시스템 글꼴. 읽기 좋은 14~16px 본문과 충분한 대비.
- 공통 상단 홈/AI 대화/학습 탭과 영역별 하위 메뉴 유지. 최근 수정한 로그인 영역 탐색/권한별 표시를 유지하며, 390px에서는 가로 하위 메뉴와 편한 터치 영역.
- 홈: 소개 카드 + 실제 프로젝트 이미지 카드의 벤토 구성, 포트폴리오·이력서 접근, 넉넉한 프로젝트 이미지와 카드, 소개·연락처. 공개/대표 여부·관리자 입력·프로젝트 링크/모달/필터 보존. 근거 없는 성과·숫자를 만들지 않는다.
- 이력서: 소개, 경력 타임라인, 기술·학력 카드, 프로젝트. 실제 저장 내용을 안전한 DOM 텍스트로 표시하고 기존 공개 설정·편집·인쇄를 유지한다. 기본 경력의 bullet은 의미 있는 목록으로 표시하며 일반 사용자 문단도 지원한다.
- AI 대화·학습: 같은 색상/모서리/간격/버튼/입력/카드. 대화 스크롤·전송/중지·음성, 학습 답안·복습·설정·듣기의 기존 동작을 유지한다.
- 관리/계정/PWA 화면도 공통 쉘 안에서 어색하지 않게 조정하되 기능 변경은 하지 않는다. 인쇄는 메뉴를 숨기고 이력서의 잘림·과도한 공백을 방지한다. reduced-motion을 존중한다.

## 작업 분담과 검증

ui-codex 1명: 먼저 디자인 계약의 구체적 위험을 검토한 뒤 홈·이력서 HTML/렌더링/editorial CSS 담당. main-codex: 공통 shell CSS와 AI·학습 스타일, 통합·브라우저·기록·Git 담당. 충돌하지 않도록 파일 소유를 분리한다.

기존 Node 회귀 검사 및 필요 시 DOM 렌더링 검사. 임시 계정·독립 DB의 실제 앱을 CUA로 1280px/390px에서 확인한다. 홈·프로젝트 모달/필터·이력서·대화 입력/음성 컨트롤·학습 카드와 설정·권한별 메뉴를 점검한다. 실제 운영 Mac/PDF 프린터와 휴대폰 설치는 이 환경에서 실행했다고 주장하지 않는다.
