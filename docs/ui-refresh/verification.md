# 별빛공방 UI 개편 검증

## 2026-10-30 파스텔 별빛 테마

사용자가 PC·모바일 이미지 시안을 승인한 뒤 적용했다. 크림색 바탕·연보라/핑크빛·유리 카드, 홈의 장식용 유리별과 작은 별 포인트를 사용한다. 꽃/꽃잎/나비 장식은 없다. 홈의 편집 문구·실제 대표작과 프로젝트 이미지는 유지하고, 스텔라·학습 진입 카드는 계정 권한으로 표시한다. 학습 진도 수치를 임의로 표시하지 않는다. SRPG의 미오는 캐릭터 추천일 뿐, 사이트에 초상을 복사하거나 기존 페르소나를 변경하지 않았다.

- 공통 팔레트·내비게이션·대화/학습은 `public/shared/shell.css`, 홈·이력서·포트폴리오는 `public/site/editorial.css`, 플레이 고유 영역은 `public/site/play.css`에서 관리한다. PWA와 페이지 테마 색상도 크림색으로 맞췄다.
- 기존 상단/하위 메뉴, 계정 권한, 공개/비공개와 GitHub 링크 필터, 프로젝트 모달/직접 링크, 이력서 문구와 인쇄 규칙, 대화 스크롤과 게임 iframe은 유지한다. 장식은 포인터 입력을 가로채지 않고 모션 감소 시 움직임을 끈다. 유리 필터를 지원하지 않아도 밝은 불투명 표면을 사용한다.
- `starlight-glass-star.png`는 이미지 생성 도구로 만든 투명 RGBA 장식(1,066,850바이트)이며 `/site/assets/starlight-glass-star.png` 한 경로만 공개 서빙한다. 임의 파일 경로를 노출하지 않는다. 생성한 게임 예시 이미지는 사용하지 않았다.
- 관련 검사 40개 통과, Windows 전체 228개 중 227개 통과·실패 0·파일 심볼릭 링크 권한 검사 1개 건너뜀. 새 PNG의 실제 HTTP GET/HEAD·MIME·시그니처·RGBA·미등록 경로 404 확인을 추가했다. 최종 Mac 결과는 해당 커밋의 GitHub Actions를 확인한다.
- 코드의 대표 색 대비를 계산해 본문 5.06:1, 기본 버튼의 가장 밝은 그라데이션 끝 5.10:1로 조정했다. 실제 렌더링·픽셀별 대비 검사를 대신하지 않는다.

**이번 변경의 실제 브라우저 시각 검증은 미완료다.** Work 설정에서 로컬 브라우저 사용이 꺼져 도구를 사용할 수 없었으며 사용자에게 활성화 선택을 요청했다. PC/모바일 320·390·700px의 실제 간격·가로 넘침, 모션 감소·인쇄·Safari/PWA·유리 필터 미지원 환경은 실제 확인하지 못했다. 아래 2026-10-21 캡처·시각 검증 결과는 이전 디자인의 결과이며 이번 테마의 증거로 재사용하지 않는다. 생성 시안은 실제 구현 화면 캡처가 아니다. 운영 Mac 업데이트도 수행하지 않았다.

## 적용 내용

- 홈: 소개·실제 대표 프로젝트 이미지를 나란히 배치하고 포트폴리오·이력서 접근 카드를 구성했다. 공개 API의 featured와 cover가 있는 프로젝트를 우선하며, 이미지가 없으면 기존 소개 안내를 표시한다. 프로젝트 목록 전체와 분류·상세 모달·직접 링크를 유지한다.
- 이력서: 소개 카드, 경력 타임라인, 프로젝트 목록, 기술·학력 카드를 구성했다. 입력한 일반 문단은 유지하고 `•`, `-`, `*`로 시작하는 목록만 안전한 DOM 목록으로 표시한다. 내용·공개 설정을 변경하거나 이력서 데이터를 이관하지 않는다.
- 공통: 밝은 회색 배경·흰색 카드·청록 버튼과 민트/살구 보조 색상, 같은 상단 탭·하위 메뉴·모서리·간격을 사용한다. 모바일 하위 메뉴는 가로 스크롤이며 대화 내용은 입력창과 분리해 스크롤한다.
- 인쇄: 내비게이션·편집 버튼을 숨기고 이력서를 단일 열로 표시한다. 경력 섹션 전체가 페이지를 넘기지 못하는 조건을 제거하고 제목·목록 항목 단위로 나눔을 제어한다.

|---|---|

| 모바일 390×844 | 홈·이력서·학습·단어·완료 대화 확인, 문서 가로 넘침 없음 |

| 실제 앱 브라우저 흐름 | 프로젝트 분류→상세→뒤로 가기, 상세 직접 URL→닫기, 학습 정답·해설 표시, 단어 읽기/뜻 펼침, 대화 기록 표시 확인 |
| 팀 읽기 검토 | 공통 CSS·사이트 CSS 결합, 권한 숨김, 모바일·인쇄 규칙 검토, 추가 확정 결함 없음 |

중간 폭에서 대표 카드의 비율과 최소 높이로 이미지 너비가 400px로 계산되어 옆 본문과 겹치는 문제가 있었다. 이미지 영역을 `width:100%;min-width:0`으로 제한한 후 900px 화면에서 두 열의 경계와 겹침 해소를 확인했다.

기존 테스트의 건너뜀 1건은 Windows의 파일 심볼릭 링크 권한에 따른 Certbot 백업 검사다. Mac에서의 실제 배포·Safari/PWA·PDF 인쇄 결과는 이 환경에서 검증하지 않았다. 대화 모델·음성 목록은 UI 확인용 fixture를 사용했으며 실제 Ollama 추론·Qwen 음질을 재검증한 기록이 아니다. 테스트 계정과 DB는 격리된 임시 데이터다.

## Mac 적용

관리자의 **홈 → 사이트 업데이트 → 새 버전 확인 → 확인한 버전으로 업데이트**로 적용할 수 있다. 이후 브라우저 또는 설치한 웹앱을 새로고침한다.

수동 적용 시 `starlightForge`에서 `git pull --ff-only`, `npm ci` 후 포트폴리오·AI 대화·학습의 세 Node 서버를 재시작한다. 자세한 명령은 [README](../../README.md#기존-설치-업데이트)를 따른다. 이번 변경에는 DB 마이그레이션이나 별도 모델 설치가 없다.
