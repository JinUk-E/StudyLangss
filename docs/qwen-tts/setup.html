STARLIGHT FORGE · STELLA VOICE

스텔라에게
차분한 목소리를.

Mac에서 한국어와 일본어를 합성하고, 웹과 휴대폰에서 들을 수 있습니다. 휴대폰에 모델을 설치할 필요는 없어요.

먼저 알아두세요. 코드·권한·재생 흐름은 테스트했습니다. 실제 Mac의 MLX 실행과 음질·속도는 아직 확인하지 못했습니다. 아래 두 언어 샘플을 직접 들어본 뒤 활성화하세요.

목소리가 전달되는 길

기존 HTTPS 도메인을 사용합니다. Qwen의 8877 포트는 외부에 공개하지 않습니다.

Mac에서 한 번 설치하기

STEP 01 · 준비

코드와 Python 준비

Apple Silicon · macOS 14+ · Node 24+. 기존 웹 서버와 같은 로그인 사용자로 저장소에서 실행하세요.

git switch starlightForge
git pull --ff-only origin starlightForge
npm ci
brew install python@3.12
export PATH="$(brew --prefix python@3.12)/bin:$PATH"

Python이 이미 있다면 설치는 생략합니다. python3.12는 arm64여야 합니다.

STEP 02 · 설치

모델과 자동 실행 도우미 준비

npm run setup-qwen-tts

Python 가상환경과 모델을 내려받고 로그인 후 실행되는 도우미를 등록합니다. 최초 다운로드에는 수 GB의 저장 공간과 인터넷이 필요합니다.

이 단계에서는 기존 웹 음성을 바꾸지 않습니다.
STEP 03 · 들어보기

한국어와 일본어 확인

npm run check-qwen-tts
open data/tts/qwen-check-ko.wav
open data/tts/qwen-check-ja.wav

모델 로딩 중이면 잠시 뒤 점검을 다시 실행하세요. 두 파일의 발음·자연스러움·속도·음량을 확인합니다.

한국어는 Sohee, 일본어는 Ono_Anna입니다. 두 언어의 음색이 같다고 보장하지 않습니다.

STEP 04 · 적용

점검 후 웹에 연결

npm run check-qwen-tts -- --activate
launchctl kickstart -k "gui/$(id -u)/kr.haru.jlpt"
launchctl kickstart -k "gui/$(id -u)/org.starlightforge.chat"

두 언어 합성을 다시 확인한 뒤 설정을 저장합니다. 터미널로 운영한다면 학습·채팅 서버를 직접 재시작하세요.

웹을 새로고침하고 답변 읽기 / 한국어 뜻 듣기 / 해설 듣기를 눌러 확인합니다.

기존 Nginx 설정도 확인. 현재 사용하는 설정의 학습 /api/ 응답 대기시간을 180초로 맞추고 검사·재시작하세요. Git pull만으로 운영 설정이 바뀌지는 않습니다. 구체적인 명령은 아래 설치 문서에 있습니다.

안내가 나오면 이렇게

화면 안내할 일
모델 로딩 중잠시 기다린 뒤 npm run check-qwen-tts
모델이 다른 요청 처리 중음성 생성이 끝난 뒤 다시 누르기. Ollama 동시 실행 시 Mac 메모리도 확인
서비스 버전 불일치npm run setup-qwen-tts -- --refresh → 샘플 확인 → 활성화
자동 언어가 어색함답변의 읽기 언어를 한국어 또는 일본어로 선택
iPhone에서 한 번 더 누르기 안내준비된 같은 재생 버튼을 다시 누르기
Qwen을 잠시 끄고 싶음Node의 TTS_ENGINE=mac 명시 후 재시작. 기존 일본어 음성만 사용
서비스는 내부 전용. 8877을 포트포워딩하지 마세요. data/tts/*.json에는 인증 토큰이 있습니다. 공개 Git·메신저에 첨부하지 않습니다.

설치 뒤 알아둘 것

차분하고 부드러운 말투를 고정 지시합니다. 자동 언어 구분은 글자 기반이라 섞인 문장은 수동 선택이 더 나을 수 있습니다. 읽기는 2,000자, 완성 음원은 최대 180초이며 제한을 넘으면 오류로 표시합니다.

웹의 사이트 업데이트 버튼은 Node 서버 3개를 갱신합니다. Python과 모델은 Mac에서 따로 --refresh 해야 합니다. 모델 캐시는 홈 폴더, Python 환경은 .venv-tts/에 있어 앱 데이터 백업에 포함되지 않습니다.
