사람마다 사용할 기능을
관리자가 정합니다

친구에게 줄 아이디와 비밀번호를 만들고, 학습이나 AI 대화를 선택하세요. 기존 관리자 기록은 그대로 두고 각자의 기록을 따로 보관합니다.

기존 계정이 관리자입니다. 업데이트 후 새로 가입하거나 비밀번호를 다시 설정할 필요가 없습니다.

계정 하나, 자기만의 공부방

Mac 업데이트 후 사용하기

업데이트 전 서버를 멈추고 기존 자료를 개인 백업하세요. 저장소에서 다음을 실행합니다.

git pull --ff-only
npm ci

학습·채팅·portfolio 세 서버를 모두 재시작하세요. 기존 관리자 계정으로 홈 → 계정 관리에 들어가면 됩니다.

단계입력과 조작
계정 만들기아이디, 비밀번호와 확인 → 학습·AI 중 하나 이상 선택 → 계정 추가
공유아이디·비밀번호와 사이트 주소를 사용할 사람에게 직접 전달
변경목록에서 권한 저장, 사용 중지/재개, 비밀번호 재설정

비밀번호12자 이상 · 관리자 포함 최대30계정 · 저장된 비밀번호는 다시 조회할 수 없습니다. 아이디는 변경·재사용하지 않고 삭제 대신 중지로 기록을 보존합니다.

권한이 적용되는 범위

구분동작
학습·AI선택한 기능만 메뉴에 표시하고 서버 API에서도 검사합니다.
개인 기록학습·대화·복습·백업과 알림 기기가 계정별로 분리됩니다.
관리 기능계정 관리·콘텐츠 편집·비공개 이력서·미게시 이미지는 관리자 전용입니다.
공개 홈홈과 게시한 포트폴리오는 누구나 볼 수 있습니다.
변경은 새 요청부터 적용됩니다. 진행 중인 AI 대화는 약2초마다 확인해 중단합니다. 이미 처리 중인 학습 요청이나 중계 서비스가 접수한 알림은 끝날 수 있습니다.

같은 폰에서 다른 계정을 시험한다면

상단의 현재 아이디를 먼저 확인하세요. 브라우저가 Basic 로그인 정보를 기억하므로 다른 계정은 별도 프로필이나 시크릿 창에서 확인하는 편이 편합니다. PWA와 Safari의 로그인 상태가 다를 수도 있습니다.

이전 계정의 푸시 구독이 남았으면 앱 설치·알림에서 현재 브라우저 구독을 해제하고 새 계정으로 다시 켜세요. 다른 사람의 기기 등록을 자동으로 가져오지는 않습니다.

자료 보존과 검토 결과

기존 관리자는 원래 DB를 사용합니다. 새 계정은 고정 UUID에 연결된 별도 DB를 사용합니다. 공통 계정 DB accounts.sqlite에는 비밀번호 검증값이 있으므로 기존 인증 파일과 함께 개인 백업하고 Git·학습 JSON에는 넣지 않습니다.

구버전 서버를 섞어 실행하지 마세요. 구버전에는 새 권한 검사가 없습니다. 롤백할 때는 모든 서버를 정지하고 업데이트 전 코드와 데이터 백업 전체를 함께 복원합니다.

기술·운영·사용 경험 기획 검토와 두 역할의 교차 코드 검토를 마쳤습니다. 자동 시험106개 통과, 임시3계정 브라우저에서 권한별 메뉴·개인 설정 저장·모바일 배치를 확인했습니다. 실제 Mac·휴대폰 점검은 배포 후 필요합니다.
