# Mac 기본 일본어 음성 설치·복구

한국어·일본어의 자연스러운 스텔라 음성은 [Qwen3-TTS 설치 안내](MAC-QWEN-TTS.md)를 사용하세요. 이 문서는 Qwen 설치 전 또는 `TTS_ENGINE=mac`으로 명시적으로 복구할 때 사용하는 기존 `say` 엔진 안내입니다. Qwen 활성 설정이 없으면 기존 엔진을 유지합니다. Qwen 활성 상태의 장애는 기본 음성으로 자동 대체하지 않습니다.

단어·문장·듣기 연습과 기존 청해 문제는 Mac 서버에서 만든 WAV 파일을 받아 재생합니다. 접속하는 휴대폰·PC에는 일본어 음성을 설치하지 않아도 됩니다. Mac에 설치된 일본어 음성을 사용하며 별도 유료 API, Ollama 모델, ffmpeg 설치는 필요하지 않습니다.

## Mac에서 처음 적용하기

1. 저장소의 `starlightForge` 브랜치를 업데이트합니다.

   ```sh
   git switch starlightForge
   git pull --ff-only origin starlightForge
   ```

2. **학습 서버를 실행하는 Mac 사용자 계정**에서 일본어 음성을 설치하고 다운로드가 끝날 때까지 기다립니다. 시스템 설정 → 손쉬운 사용의 말하기 관련 설정에서 일본어 음성을 추가합니다. 메뉴 이름은 macOS 버전에 따라 다릅니다. [Apple 음성 설정 안내](https://support.apple.com/ko-kr/guide/mac-help/mchlp2290/mac)를 참고하세요. 이 설정은 서버인 Mac에만 필요합니다.

3. 프로젝트 폴더에서 같은 사용자 계정으로 점검합니다. 앱 실행 시 별도 `DATA_DIR`를 사용했다면 여기에도 같은 값을 적용합니다.

   ```sh
   npm run check-tts
   open data/tts-check.wav
   ```

   점검 명령은 설치된 일본어 음성 목록, 실제 `say` 합성, WAV 변환과 형식, 두 번째 요청의 캐시 재사용을 확인합니다. 출력되는 파일 경로로 직접 들어 보고 일본어 발음·음량도 확인하세요. 점검은 로그인 비밀번호를 입력받지 않습니다.

4. 실행 중인 **학습 서버**를 중지하고 기존 방식으로 다시 시작합니다. 터미널 실행이면 `npm start`, 예제 LaunchAgent를 그대로 등록했다면 다음 명령을 사용합니다.

   ```sh
   launchctl kickstart -k gui/$(id -u)/kr.haru.jlpt
   ```

   이 Label로 등록한 경우에만 사용합니다. 음성을 설치한 로그인 사용자 권한의 LaunchAgent로 운영하세요. 다른 사용자·root LaunchDaemon·SSH 세션에서 같은 음성이 보인다고 보장하지 않습니다. 터미널 점검만 성공하고 웹에서 실패하면 실제 학습 서버의 실행 계정과 로그도 확인합니다.

5. 브라우저를 새로고침하고 학습 → 듣기 연습에서 음성 목록, 첫 재생, 반복, 속도 조절, 중지와 화면 이동을 확인합니다. iPhone/Safari가 자동재생을 차단하면 **“음성이 준비되었습니다. 재생 버튼을 한 번 더 눌러 주세요.”** 안내 후 같은 버튼을 다시 누릅니다. 전체 반복 재생이 끝난 경우에만 듣기 기록을 저장할 수 있습니다.

기본 일본어 음성 설치는 학습 서버에 적용합니다. Qwen에서 복구하며 엔진 설정을 바꾸는 경우에는 [두 Node 서버의 복구 절차](MAC-QWEN-TTS.md#mac-기본-일본어-음성으로-복구)를 따르세요. 기존 `starlightforge.conf.example`의 `/api/` 경로를 사용한다면 Nginx 설정은 변경할 필요가 없습니다.

## 동작과 제한

인증된 `GET /api/tts/voices`가 설치된 일본어 음성을 조회하고, `POST /api/tts/audio`가 저장된 학습 자료의 ID와 읽을 부분, 선택한 음성만 받습니다. 임의 텍스트·파일 경로·명령은 받지 않습니다. 서버가 자료를 찾은 뒤 `/usr/bin/say`로 AIFF를 만들고 `/usr/bin/afconvert`로 16bit mono 22.05kHz WAV로 변환합니다. 브라우저는 인증된 응답을 받아 재생 속도와 반복을 적용합니다.

외부 명령은 셸을 거치지 않는 인수 배열로 실행합니다. 텍스트는 권한을 제한한 임시 UTF-8 파일로 전달하고, 생성 결과를 검증한 뒤 캐시에 등록합니다. 다운로드한 음성의 품질은 Mac의 설치 음성과 자료에 따라 달라집니다. 실제 시험 음원이나 발음 평가 기능은 아닙니다.

- 합성은 한 번에 하나씩 처리하며, 같은 문장·음성의 요청은 공유합니다.
- 자료는 최대 2,000자, 기본 엔진의 개별 합성 작업은 최대 30초, 공통 브라우저의 음성 준비 요청은 최대 150초입니다. 기본 엔진의 대기 요청은 최대 16개입니다. 긴 대본·느린 음성·동시 요청이 많으면 시간 초과 안내 후 다시 시도할 수 있습니다.
- 계정·서비스·언어·엔진 버전·문장·음성으로 캐시를 구분합니다. 재생 속도·반복만 바꾸면 원본 음성을 재사용합니다.
- 완료된 캐시는 기본 `data/tts-cache/`에 저장하며 새 파일 등록 시 오래된 항목부터 정리해 128MiB 이내로 유지합니다. 개별 완료 WAV는 최대 16MiB입니다. 생성 중 임시 파일은 별도이며 실패·취소·정상 종료 시 정리합니다.
- 캐시·임시 파일은 공개 정적 경로에 노출하지 않습니다. 음성 응답은 기존 인증·출처 검사와 `Cache-Control: private, no-store`를 사용합니다.
- 캐시는 재생성할 수 있으므로 학습 JSON 백업에 포함하지 않습니다. 복습 기록과 인증 정보의 저장 방식은 유지합니다.
- macOS가 아니거나 일본어 음성을 사용할 수 없으면 이유를 표시합니다. 단어·문장 학습과 대본 확인은 계속 사용할 수 있습니다.
- 이 엔진에서는 한국어 뜻·해설과 자동 언어 선택을 사용할 수 없습니다. 한국어 음성은 Qwen3-TTS 설치·활성화 후 지원합니다.

설치 확인이 필요하면 Mac에서 `/usr/bin/say -v '?'`로 같은 실행 계정에 보이는 음성을 확인할 수 있습니다. 목록에 일본어 음성이 없으면 다운로드 상태와 사용자 계정을 확인하세요. 웹의 음성 목록은 잠시 캐시되므로 설치 직후에는 잠시 뒤 새로고침하거나 학습 서버를 다시 시작합니다.

## 검증 범위와 근거

Windows에서 합성 명령을 주입한 테스트로 파일 생성·캐시·동시 요청·취소·시간 초과·실패 정리와 WAV 형식을 검증합니다. 재생은 모의 Audio 엔진으로 실제 종료 이벤트, 반복, 취소, 자동재생 차단 후 재클릭과 오류를 검사합니다. 실제 macOS 명령 실행·선택한 음성의 음질·iPhone 재생은 위 점검을 해당 기기에서 통과해야 확인됩니다.

- [Apple: 텍스트 음성 파일 생성](https://developer.apple.com/library/archive/documentation/LanguagesUtilities/Conceptual/MacAutomationScriptingGuide/SpeakText.html)
- [Apple: 사용자 세션과 시스템 데몬의 실행 문맥](https://developer.apple.com/library/archive/documentation/MacOSX/Conceptual/BPMultipleUsers/Concepts/SystemContexts.html)
- [WebKit: 자동재생 거부와 play() 처리](https://webkit.org/blog/7734/auto-play-policy-changes-for-macos/)
